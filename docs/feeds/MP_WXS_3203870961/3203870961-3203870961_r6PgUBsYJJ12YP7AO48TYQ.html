中国药大董廖斌/南京大学梁勇团队Angew｜改

五环三萜的 B 环一直很难改。它没导向基团，又挤满性质相近的 C-H 键。以前靠纯化学法做，12 步总收率还不到 3%。

我们之前发现一种叫 ApPT 的酶。它能先催化 C7 位羟化，接着又一路氧化到 C15 位。这回就想拦住它，让反应停在 C7 位。

通过改造四个氨基酸，底物被推离了活性中心。后续的氧化接力直接被卡死。突变体 MB4 把 C7 位选择性做到了 99% 以上。克级放大分离收率也有 81%。

拿到这个 C7 位羟基化产物后，我又做了一串衍生化。结果很直接：B 环修饰能明显调控抗增殖活性。其中几个 C7 酰基衍生物最猛。它们对 PC-3 细胞的活性，达到了阳性对照的两三倍。

原本难碰的惰性位点，现在成了药物改造的新入口。
